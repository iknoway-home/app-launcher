# OPERATIONS.md

このファイルは、ビルド、配布、復旧の現状を記録します。

## 自動更新ルール

以下が変わった場合は、このファイルを更新してください。

- デプロイ方法、リリース手順、ロールバック手順を変えた。
- 本番環境、ステージング、監視、ログ、バックアップの扱いを変えた。
- 障害対応や復旧手順を追加・変更した。
- 運用に使う外部サービスや権限を変えた。

具体的な手順が固定化したら `.agents/skills/` にスキルとして切り出してください。

## 環境

| 環境 | 用途 | 方法 | 注意 |
|---|---|---|---|
| local browser | UI 開発 | `npm run dev` | OS 連携は動かない |
| local desktop | Windows 実機開発 | `npm run tauri dev` | Rust と Windows 向け Tauri 環境が必要 |
| staging | なし | なし | 専用の検証配布先はない |
| production | Windows 配布物 | `npm run tauri build` | 公開先と配布形式は未決 |

## ビルド手順

```bash
npm ci
npm run build
npm run tauri build
```

上記はローカル配布物を作る手順です。外部公開は別途明示的な依頼と公開先の決定が必要です。

## ロールバック

| 対象 | 手順 | 注意 |
|---|---|---|
| アプリ本体 | 以前に保管した配布物を再インストールまたは再配置 | 配布物の保管方針は未決 |
| 設定 | app-launcher/config.json のバックアップを同じ場所へ戻す | Orbit を終了してから行う。自動バックアップはない |
| Windows 自動起動 | 設定画面で無効化する | Rust が現在ユーザーの OrbitAppLauncher 値を削除する |

## バックアップ

| 対象 | 方法 | 頻度 | 復元 |
|---|---|---|---|
| 設定 JSON | 利用者が app-launcher/config.json を手動コピー | 未設定 | Orbit 終了中に元の場所へ戻す |
| アプリ本体 | ソースから再ビルド、または以前の配布物を保管 | 未設定 | 再インストールまたは再配置 |

## 障害対応

| 症状 | 初動 | 復旧 |
|---|---|---|
| 設定 JSON が壊れて起動時に読めない | 元ファイルを別名で退避する | Orbit を起動して空の設定を生成し、必要な項目を再登録する |
| 自動起動を解除できない | 設定画面で無効化後に再起動確認 | 必要なら現在ユーザーの Run キーにある OrbitAppLauncher 値だけを手動削除する |
| 配布ビルドが失敗する | npm run build と Rust/Tauri の出力を分けて確認 | lockfile と必要ツールを揃えて再実行する |
