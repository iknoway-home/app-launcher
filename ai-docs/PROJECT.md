## 概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | Orbit |
| 目的 | Windows 上で登録済みのアプリ、ファイル、URL を検索・選択し、単体または順序付きキューで起動する軽量デスクトップランチャー |
| 主なユーザー | Windows で日常的に複数のアプリを起動する利用者 |
| 利用シーン | アプリの検索・即時起動、複数アプリの一括起動、起動セットの再利用 |
| 現在のフェーズ | Phase 1〜3 の主要機能と Phase 4 の UI の一部を実装済み |
| 本番 URL | なし（Windows デスクトップアプリ） |
| リポジトリ | https://github.com/iknoway-home/app-launcher.git |

## 主要機能

| 機能 | 概要 | 入口 |
|---|---|---|
| アプリ一覧・検索 | グループ、お気に入り、名前・グループ・パスのあいまい検索で絞り込む | `src/App.tsx` |
| アプリ登録・並べ替え | 名前、パス、引数、グループ、種類アイコンを登録し、カードをドラッグして並べ替える | `src/App.tsx`、`src/store.ts` |
| 起動キュー | 複数選択したアプリを並べ替え、順番に起動する | `src/App.tsx` |
| プリセット | 選択順と起動間隔を保存し、後から一括起動する | `src/store.ts` |
| 設定永続化 | デスクトップ版は設定 JSON、ブラウザプレビューは localStorage に保存する | `src-tauri/src/main.rs`、`src/lib/tauri.ts` |
| Windows 自動起動 | 現在の実行ファイルをユーザー単位の Run キーへ登録・解除する | `src-tauri/src/main.rs` |

## 非対応範囲

- ライトテーマ、タスクトレイ常駐、グローバルホットキーは UI 上で未実装と表示される。
- Windows API による実行ファイルのアイコン自動抽出は実装されていない。
- プリセットの起動時自動実行、自動検出、設定のインポート／エクスポートは実装されていない。
- サーバー、DB、ユーザー認証、モバイル版はない。
