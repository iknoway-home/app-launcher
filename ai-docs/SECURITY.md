# SECURITY.md

このファイルは、Orbit 固有の権限、入力境界、既知リスクを記録します。

## 自動更新ルール

以下が変わった場合は、このファイルを更新してください。

- 認証、認可、権限、ロールを追加・変更した。
- 秘密情報、API キー、トークン、個人情報の扱いを変えた。
- 外部入力、アップロード、Webhook、外部 API 連携を追加した。
- セキュリティ上の制約、禁止事項、既知リスクが変わった。

秘密値そのものは書かないでください。

## 秘密情報・認証

秘密情報、ユーザー認証、ロール、外部 API トークンはありません。設定 JSON には利用者が登録した実行パスと引数が平文保存されます。

## OS 権限

| 操作 | 実装場所 | 権限・影響 |
|---|---|---|
| 通常プロセス起動 | `src-tauri/src/main.rs` の launch_app | Orbit と同じユーザー権限で任意の登録パスを起動する |
| 管理者プロセス起動 | `src-tauri/src/main.rs` の launch_app | PowerShell の RunAs により Windows の昇格確認を発生させる |
| 自動起動登録 | `src-tauri/src/main.rs` の set_startup | 現在ユーザーの Run キーに現在の実行ファイルを登録する |
| 設定保存 | `src-tauri/src/main.rs` の save_config | ユーザー設定ディレクトリ配下の JSON を上書きする |

## 入力境界

| 入力 | 現在の検証 | 注意 |
|---|---|---|
| アプリ名・パス | UI は空文字だけ拒否、Rust はパスの空文字だけ拒否 | パスの存在、種類、許可リストは検証しない |
| 起動引数 | UI で trim、Rust で空白分割 | 引用符を含む引数や空白入りの一引数を正確に保持しない |
| 設定 JSON | serde_json で Config へデシリアライズ | 壊れていると読み込みエラーになり、UI はブラウザ代替読込へ進む |
| URL・file URL | 文字列先頭の正規表現だけで判定 | ブラウザの window.open に渡す |
| プリセット待機時間 | HTML の数値入力と Number 変換 | 保存層で範囲を再検証しない |

## 外部公開面

| 公開面 | 状態 | 対策 |
|---|---|---|
| ネットワーク API | なし | なし |
| Tauri コマンド | load_config、save_config、launch_app、set_startup | main ウィンドウの core:default capability を使用 |
| CSP | 無効 | `src-tauri/tauri.conf.json` の csp が null。外部コンテンツ追加時は再検討が必要 |

## 既知リスク

| リスク | 影響 | 現在の扱い |
|---|---|---|
| 登録パスと引数がほぼ未検証 | 利用者が登録した任意プログラムを起動できる | ローカル利用者が自分で登録する前提。信頼できない設定 JSON を取り込まない |
| CSP が無効 | UI に外部入力や外部コンテンツを追加した場合の影響が大きくなる | 現状は外部 API と HTML 取込なし。機能追加前に CSP を設定する |
| 設定保存が直接上書き | 書込み中断で設定ファイルを失う可能性 | バックアップや原子的置換は未実装 |
| 管理者起動に PowerShell を使用 | 引数処理の誤りや意図しない昇格対象につながる可能性 | Windows 実機テストが必要 |
