# AIに相談リンクを実装する

## Overview

チャットAIの多くは、URLのクエリパラメータでプロンプトを受け取れます。
つまり **APIキーもサーバー処理も課金もなしに**、リンク1本でユーザー自身の
AIアカウントを「プロンプトが入った状態」で開けます。

自前でAPIを叩く場合と比べた性質:

| | URLパラメータ方式 | API方式 |
|---|---|---|
| APIキー | 不要 | 必要（秘密情報の管理が発生） |
| 課金 | ユーザー持ち（こちらは0円） | こちら持ち・従量 |
| 回答の表示場所 | ユーザーのAI画面（別タブ） | 自サイト内 |
| 回答の加工・保存 | できない | できる |

**回答を自サイトで受け取る必要がないなら、まずこの方式を検討してください。**

## 対応表（2026-08-16 本人のログイン済みブラウザで実測）

| AI | URL | 開いた後の挙動 |
|---|---|---|
| ChatGPT | `https://chatgpt.com/?prompt=<enc>` | 入力欄に入るだけ（送信しない） |
| ChatGPT | `https://chatgpt.com/?q=<enc>` | **自動送信して回答まで走る** |
| Claude | `https://claude.ai/new?q=<enc>` | 入力欄に入るだけ（送信しない） |
| Perplexity | `https://www.perplexity.ai/search/?q=<enc>` | **自動送信** |
| Grok | `https://grok.com/?q=<enc>` | **自動送信** |
| Gemini | — | **非対応**。`?q=` を付けても無視され、空の画面が開くだけ |

`<enc>` は `encodeURIComponent()` の結果です。

**自動送信の有無をUIに反映してください。** 送信まで走るAIは「押した瞬間に回答が始まる」ので、
ユーザーがプロンプトを直せません。長い・作り込んだプロンプトほど、直せる側（ChatGPT `?prompt=` /
Claude）を既定にする価値があります。

## 実装の型

1. **プロンプトを組み立てる関数を1つ作る。** 画面のデータ → 文字列。ここにドメイン知識を書く。
2. **プロバイダ定義は1か所にまとめる。** 上の表が変わったら1ファイル直せば全画面が追従する。
3. **非対応AI（Gemini）はクリップボードにコピーしてから開く。** リンクを出さない選択も可。

参考実装は `ask-ai.js`（このディレクトリ）。依存なしのESMなので、
プロジェクトの読み込み方式に合わせて取り込んでください。
**そのままコピーするのではなく、既存の書き方・命名・スタイルに寄せること。**

## Constraints

- MUST **秘密情報・認証トークン・他人の個人情報をプロンプトに含めない。**
  URLは第三者のサービスへ送られ、履歴やログに残ります。
- MUST **エンコード後のURL全体を 6000 文字以内**に収める。
  日本語1文字がエンコードで9文字になるため、素の日本語では約650文字が上限の目安です。
  超えるなら本文を全部載せず、**要約＋公開URL**を渡してAI側に読ませる。
  公開URLがないページの内容は、要点だけ抜き出す。
- MUST `encodeURIComponent()` を通す。文字列連結でURLを組み立てない。
- MUST 別タブで開く（`target="_blank" rel="noopener"`）。作業中の画面を離脱させない。
- SHOULD プロンプトに「何を答えてほしいか」を明示する。データを貼るだけにしない。
- SHOULD ボタンは1つにして、AIの選択は展開後に出す。5つ並べると画面が壊れます。
- NEVER ログイン状態や契約プランを判定しようとしない。判定できません。

## 検証

**ブラウザで実際にリンクを踏んで、プロンプトが入った状態で開くことを確認してください。**
URLを組み立てただけで「実装した」と報告しないこと。

確認する項目:

- 日本語・改行・記号（`&` `#` `+`）が壊れずに渡るか
- 一番長くなるケースで 6000 文字を超えないか
- 非対応AIのフォールバック（コピー）が動くか
